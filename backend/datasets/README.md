# Synthetic Demo Datasets
**BESCOM Power Hack 2026 – Theme 10**

> **CRITICAL NOTICE: 100% SYNTHETIC DEMO DATA**  
> All files in this directory contain purely synthetic data generated by the FaultTrace AI scenario simulator.  
> We have **no confirmed access** to BESCOM SCADA, AMI, GIS or consumer data.  
> These datasets are intended exclusively for local prototyping and algorithmic validation of the ML and graph restoration pipeline.

## Files
1. `synthetic_network_topology.json`: Synthetic 11kV radial feeders (F4, F3, F1, F2), line sections (F4-S1 to F4-S20), switches (breakers, air-break switches, tie-switches), and distribution transformers.
2. `synthetic_scada_events.csv`: Simulated trip, lockout, and voltage events with fault currents.
3. `synthetic_consumer_complaints.csv`: Simulated consumer outage, spark, and voltage reports across IVRS, App, and call channels.
4. `synthetic_weather_observations.csv`: Simulated atmospheric parameters (wind gusts, precipitation, lightning strikes).
